# Wild Rift 国际服 iOS 适配

基于 [lvlolm-recovery](https://github.com/zwthys-cyber/lvlolm-recovery)，针对国际服 `7.3.0 (2813)`、`com.riotgames.league.wildrift` 的独立 TrollStore 应用。用户目标环境为 iOS 17.0。

编译、静态校验、原始指令对照和测试均在本仓库 GitHub Actions 执行。当前服务器只进行文件检查、源代码编辑和 GitHub 操作。用户已确认 0.8.0 敌人头像成功显示；精确对齐、完整无视野覆盖与其他功能仍需分别验证。CI 通过不等同于完整实机验收。

- 选择游戏进程 `wildrift`，进入训练模式并等待角色出现后检测。
- 开启“小地图绘制”，启动“只读悬浮窗”。屏幕矩形沿用原项目配置，需要按实际手机画面对齐。
- 出现问题时导出 `lvlolm-diagnostics.json`；其中记录框架 UUID、读取阶段、采样结果和标记状态。
- 配置、英雄头像、小地图标记、血量圈、眼位筛选和诊断沿用原项目实现；自动水银和自动惩戒仍仅有判断预览，没有接入实际操作。
- 应用标识为 `local.wildrift.recovery`，与国服恢复应用分开安装。先停止其他恢复应用启动的悬浮窗。

## 当前进度

0.8.4 实机追踪已确认：敌方普通技能的原生逻辑冷却路径成功。32 个连续采样中，`logic_cooldown_read_ok=1`，引擎节点剩余时间随游戏 tick 递减（9.5 秒冷却的技能从 152306 逐样本递减至 0），总/起始时间随释放更新；同一敌方英雄的同步镜像剩余字段保持为零，证明 0.8.3 的零值来自镜像而非游戏状态。敌方召唤师技能不在原生管理器 +0x2d8 列表中（`skill_not_found`），仍走同步诊断；原生召唤师管理器已定位到逻辑英雄 +0x360、列表 +0x60/+0x68、资源 ID +0x74，冷却节点偏移待补全。普通技能冷却的实机验证仅覆盖训练模式单个敌方英雄，常规对局、锁定状态、大招分类和隐藏小技能仍需核对。

0.8.4 的独立逻辑冷却读取路径从身份匹配的逻辑英雄读取原生技能管理器，以唯一资源 ID 对应当前技能，再读取原生冷却节点。匹配、拥有者或列表校验失败时保留同步诊断，不使用配置 CD 或时间差补值；未确认的零值仍标为“待核”。

0.8.3 是冷却问题诊断包：用户已确认 0.8.2 面板可见，但释放技能后持续显示 0 秒，冷却正确性尚未解决。新版将未确认的零值显示为“待核”，空节点显示“?”，并补充节点地址、总时间、起始时间及 CD1/CD2 字段，保留当前读取而不推算倒计时。通过原始 GetRSkill 配置路径分类大招，接入“隐藏小技能”；分类失败保留原始槽号并继续显示，均待手机验证。


0.8.1 新增野怪小地图标记和当前血量文字，接入“野怪绘制”“隐藏野怪血量”、中立颜色和血量文字大小。分类、生命或位置不可读时清除标记，不显示历史位置。野怪刷新倒计时尚未实现。

完整已实现/待验证/未实现清单见 [功能状态](docs/FEATURES.md)。所有已发布及本轮新增功能保持只读，不向游戏内存写入，不注入游戏代码，不自动点击。

国际服框架使用 dyld chained fixups。静态解析在内存副本中解析本地 rebase，保留原始输入；格式依据 [Apple fixup-chains.h](https://github.com/apple-oss-distributions/dyld/blob/main/include/mach-o/fixup-chains.h)。框架、元数据哈希与所恢复版本精确绑定，运行时仍检查 UUID 和类名。

[国际服布局](analysis/international-layout.json)记录已选类型、字段和命名方法的入口；[国际服选定汇编](analysis/international-selected.asm)用于独立检查。`analysis/ios-*`、`analysis/device-*` 和原有设备反馈属于上游国服历史证据，不代表国际服通过验证。

## GitHub 构建

在 Actions 执行 `Build TrollStore IPA`，或推送版本标签以发布安装包。发行版本和构建记录提供 SHA-256。游戏 IPA、框架和完整元数据不进入源码、安装包或源码压缩包。

原始输入仅以加密临时附件提供给 CI，解密口令存为 Actions Secret。解密后的文件仅存在于临时 runner 的 `inputs/`，工作流结束时清理；只上传选定布局、汇编、校验结果和本工具的构建产物。

源代码保留原项目 TrollSpeed MIT 许可与图片来源说明，见 `ios/TrollSpeed-LICENSE.txt` 和 `ios/Assets/README.md`。
