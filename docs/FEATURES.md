# 国际服功能状态

适配目标：国际服 7.3.0 (2813)，iOS 17.0 / TrollStore。当前开发保持只读：读取游戏、在本工具窗口绘制，不向游戏进程写入、不注入游戏代码、不发送触控。

| 功能 | 当前状态 | 仍需完成或确认 |
| --- | --- | --- |
| 国际服识别、独立安装、悬浮窗 | 已实现 | 用户反馈敌人头像成功显示；未做所有设备兼容验证 |
| 小地图敌方头像、移动补间 | 已实现，用户确认当前场景可见 | 精确位置、红方方向、五个存活敌人的持续无视野移动覆盖仍需同场日志 |
| 英雄血量圈 | 已实现 | 国际服实际血量变化与画面对照 |
| 敌方眼位标记 | 已实现 | 放眼、无视野、排眼与销毁实测；仅显示客户端中实际可读的对象 |
| 野怪小地图标记、当前血量 | 0.8.1 新增 | 真机核对野怪位置、血量变化、死亡后移除；支持关闭及隐藏血量 |
| 野怪刷新倒计时 | 未实现 | 需要恢复真实刷新状态和时钟；不根据对象消失猜测刷新 |
| 敌方技能冷却面板 | 未实现 | 需要敌方技能读取、技能身份/槽位验证及布局；本机已有技能快照不代表敌方读取已完成 |
| 主画面实体框、射线、实体头像/血量/技能 | 未实现 | 需要恢复相机投影和屏幕坐标，现有小地图投影不能代替 |
| 眼位视野范围 | 未实现 | 需要实际眼位类别及视野半径证据 |
| 惩戒 | 已有本机技能快照和只读判断预览 | 实际伤害、范围、可释放条件尚未实机核实；没有实际释放 |
| 水银 | 已恢复规则核心 | 尚未接入本机控制状态/装备读取，没有实际操作 |
| 游戏视角调整 | 未实现，不在当前只读开发范围 | 保留原配置字段；不会修改游戏相机或内存 |
| 自动操作 | 未实现，不在本轮开发范围 | 当前没有触控后端，打开原配置开关也不会自动点击 |
| 57 项 INI 配置 | 已恢复读写和原始默认值 | 保留配置字段不代表其对应绘制/操作功能已完成；界面会注明未实现项 |

0.8.1 的野怪以已读 `BattleActor.isMonster` 分类和当前 `attribute.curHP` 为依据；仅绘制身份唯一、分类成立、正血量、有当前有效坐标的对象。小兵、建筑、英雄和已确认眼位不作为野怪显示。野怪不参与敌方英雄的头像、血量圈或五人覆盖计数。

野怪标记使用中立颜色，先绘制野怪再绘制英雄，血量文字可通过“隐藏野怪血量”关闭。修改配置后重新启动/更新悬浮窗。诊断的 `minimap.monsters` 和有界追踪的 `monsters` 保存读取与标记结果；未读到的野怪不会显示历史位置或伪造刷新倒计时。
